# 顧客管理Webアプリ Ver.2 設計メモ


## Ver.2の目的

Ver.1で実装した顧客管理機能を引き継ぎながら、
React / Node.js を使った構成へ再設計する。

Ver.2では、固定された顧客管理画面ではなく、
店舗ごとの運用に合わせて項目をカスタマイズできる仕組みを追加する。


## 使用予定技術

- React
- Node.js
- Googleスプレッドシート
- Google Drive
- Gemini API


## 対応する店舗

Ver.2では対象業種を以下の3種類に絞る。

- 飲食店
- 美容系店舗
- アパレル


## 共通必須項目

3業種すべてで、以下の3項目は必須とする。

- 顧客名
- 来店日
- 会計金額

これらは管理者によるON / OFFの対象外とする。

顧客IDや来店IDなどのシステム内部IDは、
ユーザーが入力する項目ではなく自動生成する。

## 顧客項目のカスタマイズ

管理者は、店舗の運用に合わせて顧客項目を設定できる。

### 標準項目

共通必須項目以外の標準項目は、
管理者がON / OFFを切り替えられる。

OFFにした項目は画面上では非表示にするが、
すでに登録されているデータは削除しない。

再びONにした場合は、
過去に登録したデータも再表示できるようにする。

### カスタム項目の入力形式

カスタム項目を追加するときは、
以下の入力形式から選択できる。

- テキスト
- 数値
- 日付
- 選択式
- ON / OFF


## 管理者機能

Ver.2では、店舗設定を変更できる管理者向け機能を追加する。

管理者はユーザー名とパスワードで管理画面へログインする。

管理者画面では、以下の設定を行えるようにする。

- 標準項目のON / OFF
- カスタム項目の追加
- カスタム項目のON / OFF
- スタッフ管理
- 削除済み顧客の確認
- 顧客の復元

Ver.2ではスタッフごとのログインや細かな権限設定までは実装せず、
管理設定を変更できる管理者アカウントを用意する。


## 業種別の管理者アカウント

Ver.2では、以下の3業種を想定した管理者アカウントを用意する。

- 飲食店
- 美容系店舗
- アパレル

パスワードそのものによって業種を判断するのではなく、
管理者アカウントに店舗業種や設定情報を紐づける。

ログイン後は、
その管理者アカウントに保存されている設定を読み込み、
業種や店舗設定に応じて表示する項目や画面内容を変更する。

これにより、同じ顧客管理Webアプリでも、
店舗ごとに異なる使い方ができる構成を目指す。


## スタッフ管理

管理者は、店舗で使用するスタッフ情報を管理できる。

登録されたスタッフは、
顧客登録や来店登録の「担当スタッフ」などで利用する。

Ver.2ではスタッフ情報の管理までとし、
スタッフごとのログインや権限管理はVer.3で追加する予定。


## 顧客の削除・復元

Ver.2では、Ver.1で未実装だった顧客の削除・復元機能を追加する。

顧客を削除するときは、
Googleスプレッドシート上のデータを完全に消去するのではなく、
状態を変更する論理削除を使用する。

削除された顧客は通常の顧客検索や一覧から除外する。

管理者は削除済み顧客の一覧を確認でき、
必要に応じて顧客を復元できるようにする。

顧客を復元した場合は、
過去の来店履歴や顧客写真などの関連データも
再び利用できる状態にする。

Ver.2では、Ver.1で実装した主要機能を原則として引き継ぐ。

- 新規顧客登録
- 常連顧客の来店登録
- 顧客検索
- 詳細検索
- クイックフィルター
- 並び替え
- 顧客詳細
- 顧客情報編集
- 複数写真登録
- 代表写真設定
- 特徴タグ管理
- ホームダッシュボード
- サマリー
- 最近追加した顧客
- 最近見た顧客
- 未登録項目ToDo
- 類似顧客確認
- PC / スマートフォン対応

これらをそのままコピーするのではなく、
React / Node.jsを使用した構成に合わせて再設計する。


## Ver.2で追加する主な機能

Ver.2では、Ver.1の機能に加えて以下を追加する。

- 顧客の論理削除
- 削除済み顧客の復元
- 管理者ログイン
- 業種別の初期設定
- 標準項目のON / OFF
- カスタム項目の追加
- スタッフ管理
- Gemini APIを利用したAI機能


## Ver.3で追加予定の機能

以下はVer.2では実装範囲を広げすぎず、
Ver.3で追加する予定とする。

- PostgreSQLへの移行
- スタッフごとのログイン
- 管理者 / 店長 / 一般スタッフなどの権限管理
- ダッシュボード表示内容のカスタマイズ
- 初回セットアップ用アンケート
- 業種や店舗運用に応じたおすすめ設定の提案
- より実運用を意識した認証・セキュリティ強化
